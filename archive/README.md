# Archive

Graphics saved from the WordPress site at matchminer.org before it was retired. Nothing in this folder is published; Quarto only copies `assets/img/**` and files the pages reference.

- `wordpress/matchminer-ui-mockup.png`: despite the name, an architecture diagram (patient data + CTML → MatchEngine → trial options), not a UI screenshot.
- `wordpress/ctml-section.png`: annotated example CTML document (KRAS colorectal trial; shows `!` exclusion syntax).
- `wordpress/mode-*.png`: clip-art illustrations of the three modes of use.
- `wordpress/goals.png`, `wordpress/matchminer-logo.png`: old goals graphic and the 200px MatchMiner wordmark.
